## О проекте

GreenGlow — одностраничный сайт магазина натуральной косметики: уход за кожей
и телом без парабенов, силиконов и синтетических красителей. На странице есть
первый экран, блок о бренде, преимущества, каталог из шести товаров, отзывы,
форма подписки и контакты.

**Стек:** HTML5, CSS3, немного JavaScript для мобильного меню и формы подписки.
Сайт не требует сборки: все файлы отдаются как есть.

## Локальный запуск

```bash
python -m http.server 8000
```

После запуска сайт доступен по адресу `http://localhost:8000/`.

## Публикация

Сайт публикуется на GitHub Pages автоматически при каждом push в ветку `main`.
Сборку и развёртывание выполняет workflow GitHub Actions, описанный в
`.github/workflows/deploy.yml`.

**Адрес сайта:** https://knat43-t.github.io/greenglow-lr6/
